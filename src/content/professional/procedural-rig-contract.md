A short-term contract covering rigging for a set of creatures ranging from quadrupeds to multi-limbed designs, delivered on a tight per-creature turnaround.

Adapted an existing procedural rigging base (built for an earlier personal project) to handle arbitrary limb counts and proportions, so each new creature could reuse the same control scheme instead of starting from a blank rig.
