Joined a four-person indie team for a few months to establish a consistent stylized shading language before the rest of production ramped up.

Delivered a small set of master shaders (skin, cloth, metal, foliage) with artist-facing parameters, so the rest of the team could apply a consistent look without needing to write shader code themselves.
